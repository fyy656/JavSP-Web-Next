# JavSP WEB v2.2.0

媒体库内置播放器上线：能在浏览器里直接播放的走本地直连，其余格式交给媒体服务器转码；同时把「打开/还原/删除」这类会操作宿主机的功能收敛到本机，并修掉一批刮削与播放相关的问题。

## 新增

- **媒体库内置播放器**：把鼠标移到影片海报上会出现圆形播放入口，点击弹出按 1920×1080 上限自适应的播放大窗（也可在资料页点「播放」），关闭方式支持按钮、`Esc` 与点击遮罩。
- **播放器能力**：进度条、音量、倍速、画中画、网页全屏、快捷键、以及“上次看到哪里”的续播记录（保存在当前浏览器）。
- **本地直连播放**：mp4 / m4v / mov / webm 这类浏览器能解的容器由程序直接分段推流，零转码、秒开、可随意拖动，不需要媒体服务器在线。
- **转码兜底**：avi / wmv / m2ts / mkv 等容器自动交给 Emby / Jellyfin 转码成渐进式 MP4 再播放；两条路互相兜底，播放失败会自动换另一条。

## 改进

- **播放条目匹配**：全库搜索媒体服务器（不再受“管理的媒体库”勾选限制），按「绝对路径 → 文件名 → 番号唯一命中」依次匹配，**不依赖路径映射**；路径映射只保留给下载器与整理后刷新媒体服务器。
- **关闭即停止**：关闭播放器会立刻断开连接并请求服务端终止这条流（按影片维护活动流，不等 socket 超时），走转码时同时结束媒体服务器的转码会话，避免磁盘与网络继续满载；关闭浏览器标签页也会发出停止请求。
- **流日志**：服务端记录「开始 / 已叫停 / 结束本地直连播放」及发送量，方便排查占用问题。
- **本机专属操作**：打开文件所在目录、系统选择框（选择文件夹/文件/路径）、还原文件、删除图片等只对运行服务的主机开放，局域网设备既看不到入口，直接调接口也会被拒绝。
- **任务重试**：失败任务可直接「重新刮削」，工具栏「重试失败」可批量重新入队（已在本机队列中的会自动跳过）。
- **文档**：补充播放、流生命周期、路径映射定位、本机专属操作的说明。

## 修复

- 引擎选择封面时 `UseJavDBCover` 未导入导致的刮削失败。
- 播放地址中 `api_key` 重复拼接导致媒体服务器返回 401（表现为黑屏、0:00）。
- 播放器关闭后仍持续传输/读盘（含 `WinError 10054` 噪音日志）。
- 媒体库刮削成功后卡片不刷新、NFO 被第三方改写成空壳后显示“缺资料”。
- 同一目录多部影片被误合并为一个条目、连带写错 NFO。
- 分类统计不随分类/搜索变化，分类下拉切换后主内容不更新。

## 升级方式

- Windows：下载本页面的 `JavSP-Web.exe`，保留原 `data` 目录即可。
- Docker：`docker pull ghcr.io/fyy656/javsp-web-next:2.2.0`（或 `:latest`）。
- 升级前建议备份 `data` 目录；如遇播放异常，可先用「扫描」重建一次媒体库索引。
