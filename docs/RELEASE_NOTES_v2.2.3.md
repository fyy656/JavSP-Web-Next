# JavSP WEB v2.2.3

媒体库细节修复版：扫描只作用于当前选中的媒体库，详情页的女优名可以直接点进该女优的影片列表。

## 修复

- **扫描范围**：在「全部影片」汇总视图下点「扫描」不再遍历并扫描所有媒体库；扫描只针对当前选中的具体媒体库。「全部影片」下隐藏扫描按钮，并提示先选择媒体库。
- **分类下拉同步**：从详情页跳转到女优分类后，「分类」下拉框同步显示当前分类。

## 新增

- **女优名可点击**：影片详情的女优名现在是链接，点一下即可跳到该女优的分类影片列表（支持多女优，保留当前媒体库 / 全部影片的浏览范围），顶部可返回女优列表。
- 同步更新使用教程与离线交互示例。

本版没有数据库结构或接口变更，可直接覆盖升级。

## 升级方式

- Windows：下载本页面的 `JavSP-Web.exe`，保留原 `data` 目录即可。
- Docker：`docker pull ghcr.io/fyy656/javsp-web-next:2.2.3`（或 `:latest`）。
