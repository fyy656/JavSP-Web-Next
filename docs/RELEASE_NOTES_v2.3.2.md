# JavSP Next v2.3.2

播放器细节修正、账号权限收紧，并补上剧集资料编辑；同时发布首个安卓客户端 **JavSP for Android 1.0.0**。

## 命名调整

- 产品名由「JavSP WEB」改为「JavSP Next」，网页标题、登录页、托盘与接口名称同步更新。
- Windows 单文件包命名为 **`JavSP-Web-Next-2.3.2.exe`**（包名带版本号）。

## 新增

- **剧集资料编辑**：剧集页的「编辑资料」写 `tvshow.nfo`；分集卡片上的「编辑」写该集自己的 `episodedetails` NFO（含季集号与播出日期）；季标题右侧的「季资料」写 `season.nfo`。保存前保留 `.bak`，并保留 NFO 中其它程序写入的标签与注释。
- **安卓客户端 1.0.0**（JavSP for Android）：媒体库浏览、排序、分类浏览（女优 / 片商 / 年份）、扫描、刮削、影片 / 剧集详情与资料编辑、内置播放器（上下集、直连与转码切换、倍速、画面比例、竖屏资源自动竖放）。

## 修复

- **安卓播放器底部白条**：进入播放器时隐藏系统栏，全屏沉浸，退出恢复。
- **安卓画面比例切不回**：切换比例后立即生效，不再需要重新打开播放器。
- **安卓强制横屏**：改为「自动 / 锁横 / 锁竖」三档，自动档按视频比例决定，竖屏资源不再被强行横过来。
- 剧集资料保存后状态被误判、原始 NFO 保存后条目被覆盖等问题。

## 权限

- 修改资料、写入 NFO、刷新 NFO、单片与批量刮削仅管理员可用，其它账号会收到 403；网页与安卓端同步隐藏这些入口。浏览、播放与观看进度不受影响。

## 升级方式

- Windows：下载本页面的 `JavSP-Web-Next-2.3.2.exe`，保留原 `data` 目录即可（可从旧版 exe 直接替换）。
- Docker：`docker pull ghcr.io/fyy656/javsp-web-next:2.3.2`（或 `:latest`）。
- Android：安装 `JavSP-for-Android-1.0.0.apk`（应用内版本号 1.0.0，versionCode 1）。

本版没有破坏性的数据结构变更，可直接覆盖升级。
