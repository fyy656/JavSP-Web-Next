# JavSP WEB v2.0.0

重构后的第一个正式版本。媒体库以磁盘文件为唯一可信来源重建，评论、账号、主题与 AI 能力全面升级。

- **媒体库**：全新「媒体库」页面，直接索引磁盘上的视频、NFO 与图片。支持多个媒体库与多文件夹、后台扫描、多段视频自动合并、按番号/标题/女优/路径搜索、按女优/片商/年份分组、隐私模式模糊封面、NFO 查看编辑、定位文件、库内直接刮削。媒体库与任务记录解耦，删除任务不会让影片消失。
- **评论系统**：影片详情页支持评论、回复、Markdown 渲染与时间点跳转；支持点赞与自适应人机验证。
- **匿名评论身份**：用户名 + 6 位 PIN 创建跨设备评论身份，可在个人中心选择头像。
- **主题**：新增亮色 / 暗色主题。
- **AI 能力**：AI 对话工作台（流式回复、会话管理）、AI 刮削（可配置为爬虫失败时回退）、AI 翻译（标题与剧情中文化，译文经完整性与番号保留检查）、可管理 Skills、上下文自动压缩、模型发现、AI 网页检查。
- **下载与媒体服务器联动**：连接 qBittorrent 下载完成后自动刮削；整理完成后自动刷新 Emby / Jellyfin 媒体库。
- **CookieCloud**：定时同步浏览器 Cookie 到爬虫凭据。
- **安全**：登录失败限流（每 5 分钟每 IP 30 次、每用户名 10 次）、会话撤销、配置脱敏、可信代理校验与 HTTPS Secure Cookie。
- **修复**：短 Cookie 值破坏 AI 网页链接、正式版/体验版渠道切换与版本比较、评论分页与详情页交互、挂载盘路径检查（winError 1005）、多段视频命名带画质后缀的整理问题。

升级方式：Windows 用户下载本页面下的 `JavSP-Web.exe`，保留原 `data` 目录即可；Docker 用户更新镜像为 `ghcr.io/fyy656/javsp-web-next:2.0.0`。升级前建议备份 `data` 目录。
