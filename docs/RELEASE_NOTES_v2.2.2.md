# JavSP WEB v2.2.2

日志与显示细节改进版：服务端日志覆盖播放（直连 / 转码）与刮削全过程，缺少标题的影片不再用可能错误的番号当标题。

## 改进

- **运行日志补全**：控制台日志统一由 `javsp_web` 命名空间输出，覆盖三类事件：
  - 本地直连：开始（番号、客户端 IP、Range、长度）与结束（发送量、用时、结束原因）
  - 转码播放：开始（服务器、条目、HLS/MP4、起始位置）与停止（会话、是否取消成功）
  - 刮削任务：开始（目录/番号、任务、并发）、结束（结果、用时、返回码）、异常原因
- **缺少标题时用文件名显示**：卡片与详情窗口的大标题改用文件名（去掉扩展名），副标题显示「缺资料 · 番号」，避免把 NFO 里可能是错的番号当成片名。
- **播放状态自动同步**：从直连自动切换到转码后，播放器左上角状态与右上角切换按钮立即更新，不用手动点一次。

## 修复

- 切换播放模式时播放窗口被异步 `close` 事件误关。
- 关闭/切换播放器后残留 `<video>` 仍在播放声音。

## 关于仓库

本版本同时移除了仓库内的内部验收资料（历史记录也已重写），`data/` 与本地环境信息不进入公开仓库。

## 升级方式

- Windows：下载本页面的 `JavSP-Web.exe`，保留原 `data` 目录即可。
- Docker：`docker pull ghcr.io/fyy656/javsp-web-next:2.2.2`（或 `:latest`）。
