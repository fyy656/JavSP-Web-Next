# JavSP WEB v2.2.1

播放体验修复版：所有格式默认先直连、播不了才转码；转码改用 HLS，进度条可以拖动；播放器里可以直接切换直连/转码。

## 改进

- **默认一律直连**：mp4 / mkv / avi / wmv / m2ts / mpg / flv / rmvb 等所有视频容器都先由本站 Range 推流，浏览器打不开时才自动转码，不再按容器“预先判定”。
- **转码改用 HLS**：媒体服务器转码优先输出 HLS（m3u8）分片，**进度条可以拖动**；放不出来时仍有渐进式 MP4 兜底。播放器内置 hls.js（随程序分发，不联网加载），iOS 使用原生 HLS。
- **直连 / 转码一键切换**：播放窗口右上角新增切换按钮，可手动指定走哪条路，切换后**从当前进度继续**播放。
- **卡住自动转码**：直连 6 秒内仍没有画面（例如 MP4 里装的是 HEVC），自动改用转码播放并给出提示。

## 修复

- **播放条目定位**：改为只以**文件路径与文件名**匹配（先按绝对路径精确查询，再按库索引里的路径/文件名匹配）。媒体服务器里的标题经常不含番号（例如只显示片名），之前按标题/番号搜索会报“没有找到这部影片”；路径映射也不再参与播放定位。
- **切换模式时播放窗口被关闭**：`dialog.close()` 的关闭事件是异步的，会在新播放启动后才到达，导致窗口被误关；现在切换时保留窗口并屏蔽该事件。
- **关闭后仍有声音**：ArtPlayer 销毁后内部 `<video>` 可能残留在页面继续播放，现在会停掉并清空所有残留媒体元素。

## 升级方式

- Windows：下载本页面的 `JavSP-Web.exe`，保留原 `data` 目录即可。
- Docker：`docker pull ghcr.io/fyy656/javsp-web-next:2.2.1`（或 `:latest`）。
