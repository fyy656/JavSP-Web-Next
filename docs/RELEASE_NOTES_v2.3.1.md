# JavSP WEB v2.3.1

剧集播放更顺手：播放器可以直接切上一集 / 下一集，各处返回按钮也做得更显眼。

## 新增

- **播放器上一集 / 下一集**：剧集播放时顶栏出现「⏮ 上一集」「下一集 ⏭」，可以连续追剧；播到一季的头尾会自动跨到相邻季（下一季从第一集开始，上一季从最后一集开始）。电影不显示这两个按钮，第一集和最后一集的对应按钮置灰。

## 改进

- **返回按钮更显眼**：剧集页的「← 返回剧集列表」和分类浏览的「← 返回女优 / 片商 / 年份列表」改为统一的蓝色胶囊按钮，悬停加深，不再是一行容易被忽略的小字。
- 播放器顶栏按钮支持换行，窄屏下不会挤成一团。

本版没有数据库结构或接口变更，可直接覆盖升级。

## 升级方式

- Windows：下载本页面的 `JavSP-Web.exe`，保留原 `data` 目录即可。
- Docker：`docker pull ghcr.io/fyy656/javsp-web-next:2.3.1`（或 `:latest`）。
